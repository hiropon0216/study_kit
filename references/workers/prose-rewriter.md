# yomiyasu で書き直す担当（フェーズ4-2）

妥当性レビューで内容を確かめたあとに、1回だけ行う。章ごとに新しいサブエージェントを立て、同時に走らせる。章ごとに別のファイルを書くので衝突しない。

```
Agent:
  subagent_type: general-purpose
  model: sonnet
  description: "yomiyasu で第[N]章を書き直す"
  prompt: |
    教材の地の文と解説文を、読みやすい日本語に書き直してください。

    ## 読むもの
    - 書き直しの基準：[YOMIYASU_SKILL]（最初に読み、ドメイン `tech` で適用する）
    - 書き直す文章：[PROSE_FILE]

    ## 決まり
    - `<!-- prose: ID -->` の目印は1つも消さず、順番も変えない。目印と目印の間の文章だけを書き直す
    - 事実の意味を変えない。「〜の場合がある」を断定にしない。条件・数値・単位・バージョン・
      コマンド名・オプション名・主語・否定をそのまま残す
    - `**何か：**` などの見出しで始まる段落は、固有名詞の前提の説明。短くまとめず、見出しも残す
    - `` `x` ``（コード）、`**x**`（覚えてほしい語）、`[x](url)`（リンク）の印は残す。
      `**x**` の語を別の語に言い換えない
    - 段落を分けるのは地の文だけ。`#explanation` で終わる目印の中（問題の解説）は1段落のままにする
    - あなたはさらにサブエージェントを呼ばない
    - 出力：[OUTPUT_FILE]

    最後の返事は「書き直した段落 N 件 — [OUTPUT_FILE]」の1行だけにしてください。
```

## 埋めるもの

- `[YOMIYASU_SKILL]`：フェーズ4-0 で見つけた `yomiyasu/SKILL.md`
- `[PROSE_FILE]`：`<出力先>/work/prose/prose_chN.md`（総合演習は `prose_final.md`）
- `[OUTPUT_FILE]`：`<出力先>/work/prose/revised_chN.md`（総合演習は `revised_final.md`）
