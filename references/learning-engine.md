# 学習エンジンの仕様（assets/template.html）

教材を作るときに template.html を書き換える必要はない。この文書は、学習者に使い方を説明するときと、template.html を直すときに読む。template.html を変えたら、必ずこの文書も合わせる。

## 基本方針

**判断はシステムがすべて行い、学習者の操作は最小にする。** 学習者がするのは次の3つだけ。

1. 答える（選択肢を押す、または入力して Enter）
2. 間違えたときに「次へ」を押す（正解なら自動で進む）
3. 覚える価値がないと思った問題に「この問題はもう出さない」を押す（任意）

節のページでは、このほかにページをめくる（← →）、予告問題を見たら「確認したので読む」、読み終えたら「読んだので答える」を押す（どちらも Enter）、2回目に開いた項目の伏せ字を押して開く（任意）がある。

考える時間、正誤の判定、次に出す日、いつ覚えたことにするか、何を出すかは、すべてシステムが決める。自己採点や自信の申告はさせない。

## 1問の出し方

1. **考える時間**：選択式（choice・predict・truefalse）は、問題文だけを出し、3秒後に選択肢を自動で出す。入力式（fill）と並べ替え（order）はすぐに答えの欄を出す
2. 節のページの問題（すぐ確認）は**予告問題**として、項目ごとに次の3段階で出す。まだ一度も正解していない問題がある項目だけ
   1. **予告問題**：見開きを開く前に、その項目の問題を1枚で見せ、答えを**予想**させる。選択式は選択肢、○×は ○ と ×、穴埋めは入力欄で予想する（並べ替えは予想しない）。予想は記録せず、正誤も出さない。予想は任意で、ボタンはすべて予想すると「予想したので読む」、そうでなければ「予想せずに読む」。ここで「この問題はもう出さない」にもできる
   2. **読む**：見開きを開く。左ページが教科書、右ページは問題を隠し「読んだので答える」だけを出す（「問いをもう一度見る」で予告問題に戻れる。予想は残っている）
   3. **答える**：右ページに問題が見え、1問目はすぐ答えの欄が出る（考える時間なし。読みながら考えている）。1項目に問題が複数あるとき（節の重要度に比例して増える）は上から順に答える（正解なら1.2秒後、不正解なら「次の問題へ」で次の問題の答えの欄が出る）
   - 項目ごとにどの段階まで進んだかは、節を開いているあいだ覚えておく。扉の「読む前に思い出す」の問題は、画面に入ったときに考える時間を始める
3. **判定**：正解か不正解かだけで決める。回答時間は測らない（速さの基準は問題ごとに違い、正しく決められないため）
4. **結果**：正解・不正解とも、正解と解説を出す。誤った選択肢に `optionNotes` があれば、その解説も出す。次に出す日（または「覚えました」）を一言添える
   - 予告問題で予想した問題は、「読む前の予想：「〜」… 当たっていました／外れていましたが、読んで正しく答えられました／外れていました」を添える
   - 間違えた問題が、まぎらわしい項目の組（`confusables`）に入っていれば、「⇄ 見分けるポイント」として組の `note` を出す
5. **次へ**：演習・今日の想起では、正解なら1.2秒後に自動で次へ進む。不正解なら「次へ」（Enter）を待つ

## 覚えた（クローズ）とする条件

| 最初の結果 | クローズの条件 | 目安 |
|---|---|---|
| 初回に正解 | 翌日以降の出題日に、もう一度正解 | 2回・翌日 |
| 一度でも間違えた | 間違えた日の翌日から、日を変えて3回正解（間隔は 1日 → 1日 → 3日） | 3回・約5日 |

- 数えるのは「出題日が来た日の、その日に間違えていない正解」だけ。同じ日の2回目以降の正解や、出題日より前の正解は数えない
- 間違えたら、それまでの回数は0に戻り、3回のコースで翌日から数え直す（初回に正解した問題も、あとで間違えたら3回のコースになる）
- クローズした問題は今日の想起に出さない。章末演習・総合演習で出て間違えたら、クローズを解いて学び直す（練習は記録しない）

## 同じ日の再出題

- 節のすぐ確認で間違えたら、次のページ（最後の項目ならまとめのページ）の右ページにもう一度出す。間違えたページに戻っても、その場では解き直させない
- 演習・今日の想起で間違えたら、3問あとにもう一度出す
- どちらも、同じ問題は1回の中で3回まで。同じ日の再出題の正解は、クローズの回数に数えない

## 何を出すか（システムが組み立てる）

| 場面 | 出す問題 |
|---|---|
| 節のページを開いたとき | 出題日が来た問題があれば、最初に「扉」のページを出す。右ページに、この節の出題日が来た問題（一度正解したもの）と、ほかの節の出題日が来た問題を最大2問 |
| 項目のページ | 右ページにその項目のすぐ確認（予告問題。節の重要度に応じて1〜4問）。一度正解した問題は「正解済み」と出題日だけを表示し、「練習で解く」（記録しない）で解き直せる |
| 今日の想起（ホーム） | 出題日が来た問題を、出題日の古い順・間違えた回数の多い順に最大10問。同じ節が続かないように並べる。まぎらわしい項目の組に入る問題の直後には、組のほかの項目の問題（一度正解したもの）を1問並べる（下の「まぎらわしい項目」）。合わせて10問まで |
| 章末演習・総合演習 | まだ解いていない問題 → 出題日が来た問題 の順に最大10問。覚えた問題と出さない問題は出さない |
| 模擬試験 | 章末演習と総合演習から無作為に `questionCount` 問。考える時間なし・正誤を出さない・記録しない。制限時間 `minutes` 分 |

## 伏せ字（2回目に開いた項目）

- 節を開いた時点で、すぐ確認に一度正解している項目は、左ページの本文のキーワードを伏せ字にする。押すと開く。「すべて開く」もある
- 伏せるのは本文の `<strong>`。図（`figure`）・コード（`pre`）・前提の説明（`sk-premise`）の中と、「何か：」のように「：」で終わる見出し語は伏せない
- 開いた伏せ字は、その節を開いているあいだは開いたまま。節を開き直すと、また伏せる
- 伏せ字は記録しない（押した・押さないで判定は変わらない）

## 穴あき例題（`type: "faded"` の項目）

- 例題（`example`）の直後に置く、同じ考え方の例題。解き方（`sk-steps`）のうち `<li class="sk-blank">` の段を伏せる
- 伏せた段は、開くたびに伏せる（2回目に限らない）。「？ この段を自分で考えてから、押して開く」を押すと開く。開いた段は、その節を開いているあいだは開いたまま
- 後ろのすぐ確認は「類題」として出る。伏せた段を開いたかどうかは記録しない

## 言い換え問題（問題の `variants`）

- 同じ知識を別の問い方（できれば別の形式）で問う版。履歴は元の問題のIDで1つだけ持つ（クローズの回数・出題日は版をまたいで共通）
- どの版を出すかはシステムが決める：初回は元の問題。同じ日のくり返し（同じ日の再出題）は前回と同じ版。日を変えたら、前回の次の版（元 → 言い換え1 → 言い換え2 → 元 …）。練習（記録しない）は元の問題、模擬試験は無作為
- 出した版の番号を学習履歴の `form` に残す

## まぎらわしい項目（教材の `confusables`）

- 取り違えやすい項目の組（例：phase と STATUS の値）と、見分けるポイント（`note`）
- 教科書：組に入る項目の左ページの末尾に「⇄ まぎらわしいので見比べよう」と、ほかの項目へのリンクと `note` を出す
- 今日の想起：出題日が来た問題の直後に、組のほかの項目の問題を1問並べる（「⇄ 見分け」と表示）。選ぶのは一度正解した問題で、出題日が来たもの → 長く解いていないもの の順。出題日前の問題の正解は、クローズの回数に数えない（ほかの正解と同じ規則）。間違えたら、ふつうどおり学び直しになる
- 結果：組に入る問題を間違えたら、`note` を「⇄ 見分けるポイント」として出す

## 次の節へ進む条件

- その節のすぐ確認（出さない問題を除く）すべてに一度正解したら、「次の節」ボタンが開く。一度正解した記録は残るので、日をまたいでもやり直しは要らない
- 章の最後の節では、「次へ」で章末演習に進む
- 目次からは、どの節もいつでも開ける

## もう出さない（除外）

- 出題中のどの段階でも、問いの右上の「この問題はもう出さない」で除外できる（答える前でもよい）
- 除外した問題は、すぐ確認・今日の想起・演習・模擬試験のどれにも出さない。次の節へ進む条件と進捗の分母からも外す
- ⚙ 設定の「出さない問題」に一覧で出し、そこから戻せる。学習履歴の書き出しに一覧（場所と問題文）を含める
- **教材から削除する**：書き出した学習履歴を教材の作り手（study-kit）に渡すと、出さない問題を教材から削除する（`scripts/retire_questions.py`）。差し替えや補充はしない。すぐ確認を削除した項目は、右ページに問題を出さず「次のページへ」だけを出す（次の節へ進む条件からも外れる）。削除した問題は教材JSONの `retired` に記録し、作り直しで同じ問題を復活させない。作り直した教材HTMLでも学習履歴はそのまま引き継がれる

## 進捗

- 覚えた割合（上部バーとホーム）＝ 覚えた（クローズした）問題 ÷ 出題する問題（すぐ確認＋章末演習＋総合演習 − 出さない問題）。小数点以下は切り捨て
- 章カードには、節の完了数と、その章の問題（すぐ確認＋章末演習）のうち覚えた数を出す

| 画面 | 内容 |
|---|---|
| ホーム | 1段目：今日の想起（黄色のカード。今日の問題の数と「今日の問題を解く」）と覚えた割合。2段目：続きから学習（節名・すぐ確認の丸・「学習を再開」）。3段目：目次（番号付きの章カード。読了／学習中／未着手）。4段目：総合演習・模擬試験・この教材のゴール |

- 問題の状態の表示：未出題（灰）・今日出す（黄）・次は M/D（青）・覚えた（緑）・出さない（点線）

- 正解で紙吹雪。節のすぐ確認に全問正解・演習の1回目に全問正解・模擬試験の合格で大きな紙吹雪。OS で「視差効果を減らす」が有効なときは出さない
- 用語・本文・問題を検索でき、結果から節の該当項目へ移動する

## 保存

- 学習履歴はブラウザのローカルストレージに、キー `study-kit:{meta.id}` で保存する。外部の CDN やライブラリは読み込まない
- ⚙ 設定の「書き出す／読み込む」で JSON にして控えを取れる。読み込みは同じ教材IDで、同じ形式（`version`）の履歴だけ受け付ける

```json
{
  "version": 3,
  "contentId": "k8s-practical-20261005",
  "questions": {
    "q-ch1-s1-01": { "status": "learning", "track": "standard", "streak": 1, "due": "2026-10-16", "lastCounted": "2026-10-15", "wrongDay": "2026-10-14", "everCorrect": true, "attempts": 3, "lapses": 1, "lastAnswered": "2026-10-15" },
    "q-ch1-s1-02": { "status": "closed", "track": "fast", "streak": 2, "closedOn": "2026-10-15", "everCorrect": true, "attempts": 2 },
    "q-ch1-s2-01": { "status": "excluded", "prevStatus": "new", "attempts": 0 }
  },
  "memos": {},
  "lastSectionId": "ch1-s2",
  "stats": { "answered": 12, "correct": 10 }
}
```

- `status`：`new`（未出題）／`learning`（覚えている途中）／`closed`（覚えた）／`excluded`（出さない）
- `track`：`fast`（初回に正解。2回でクローズ）／`standard`（一度でも間違えた。3回でクローズ）。`streak` は日を変えて数えた正解の回数
- 以前の版が書いた `rtRatios`（回答時間の記録）は、読み込むときに捨てる。以前の版で「遅い正解」として `standard` になった問題は、そのまま3回のコースで続ける
- `form`：言い換え問題（`variants`）がある問題だけ。最後に出した版（0 が元の問題）
- 書き出したファイルには、確認用に `excludedQuestions`（出さない問題の場所と問題文）を加える
- `version` が 3 より前の履歴は形が違うため引き継がない

## 動作確認

URL に `?today=YYYY-MM-DD` を付けると、その日付として動く（上部バーに「検証用の日付」と出る）。日をまたぐ出題とクローズの確認に使う。
