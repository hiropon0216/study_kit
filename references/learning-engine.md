# 学習エンジンの仕様（assets/template.html）

教材を作るときに template.html を書き換える必要はない。この文書は、学習者に使い方を説明するときと、template.html を直すときに読む。template.html を変えたら、必ずこの文書も合わせる。

## 基本方針

**判断はシステムがすべて行い、学習者の操作は最小にする。** 学習者がするのは次の3つだけ。

1. 答える（選択肢を押す、または入力して Enter）
2. 間違えたときに「次へ」を押す（正解なら自動で進む）
3. 覚える価値がないと思った問題に「この問題はもう出さない」を押す（任意）

節のページでは、このほかにページをめくる（← →）、読み終えたら「読んだので答える」（Enter）を押す、2回目に開いた項目の伏せ字を押して開く（任意）がある。

考える時間、正誤と覚え具合の判定、次に出す日、いつ覚えたことにするか、何を出すかは、すべてシステムが決める。自己採点や自信の申告はさせない。

## 根拠にした研究知見

| 知見 | 設計への反映 | 出典（**未確認**：一次文献で確認してから確定する） |
|---|---|---|
| テスト効果：読み返すより思い出すほうが記憶に残る | 項目を読むたびにすぐ確認、日を変えて出し直す | Roediger, H. L., & Karpicke, J. D. (2006). Test-enhanced learning. *Psychological Science*, 17(3). |
| 再生のほうが再認より効く | 選択肢を出す前に、問題文だけを見せて答えを思い浮かべさせる | Kang, S. H. K., McDermott, K. B., & Roediger, H. L. (2007). *European Journal of Cognitive Psychology*, 19(4–5). |
| 連続再学習：日を分けて複数回正解させると長く残る | 日を変えて2〜3回正解したら「覚えた」とする | Rawson, K. A., Dunlosky, J., & Sciartelli, S. M. (2013). *Educational Psychology Review*, 25(4). |
| 分散効果：間隔をあけると定着する | 正解するたびに出す間隔を広げる（1日 → 3日） | Cepeda, N. J., ほか (2006). *Psychological Bulletin*, 132(3). |
| 交互練習：混ぜて解くと見分ける力がつく | 今日の想起は節を混ぜて出す | Rohrer, D., & Taylor, K. (2007). *Instructional Science*, 35(6). |
| 予告問題の効果：読む前に問いを見ると、その内容が残りやすい | 項目を読む前に、右ページに問いだけを見せる | Richland, L. E., Kornell, N., & Kao, L. S. (2009). The pretesting effect. *Journal of Experimental Psychology: Applied*, 15(3). |
| 生成効果：自分で思い出して埋めると残りやすい | 2回目に開いた項目は、本文のキーワードを伏せ字にする | Slamecka, N. J., & Graf, P. (1978). The generation effect. *Journal of Experimental Psychology: Human Learning and Memory*, 4(6). |

## 1問の出し方

1. **考える時間**：選択式（choice・predict・truefalse）は、問題文だけを出し、3秒後に選択肢を自動で出す。入力式（fill）と並べ替え（order）はすぐに答えの欄を出す
2. 節のページの問題（すぐ確認）は**予告問題**として出す：左ページを読む前に、右ページに問題文だけを見せる。読み終えて「読んだので答える」を押すと、考える時間なしで答えの欄を出す（読みながら考えている）。まだ一度も正解していない問題だけ。扉の「読む前に思い出す」の問題は、画面に入ったときに考える時間を始める
3. **回答時間**：選択肢（入力欄）が出てから答えるまでを測る
4. **結果**：正解・不正解とも、正解と解説を出す。誤った選択肢に `optionNotes` があれば、その解説も出す。次に出す日（または「覚えました」）を一言添える
5. **次へ**：演習・今日の想起では、正解なら1.2秒後に自動で次へ進む。不正解なら「次へ」（Enter）を待つ

## 判定（システムが自動で行う）

| 判定 | 条件 |
|---|---|
| good（速く正解） | 正解し、回答時間が基準以内 |
| hard（遅い正解） | 正解したが基準より遅い、またはその日に一度間違えたあとの正解 |
| again（不正解） | 不正解 |

- 回答時間の基準：選択式は 2秒 ＋ 選択肢の文字数 × 0.05秒（コード付きは ＋1.5秒）、○×は 2.5秒、入力式は 3秒 ＋ 答えの文字数 × 0.35秒、並べ替えは 4秒 ＋ 項目の文字数 × 0.06秒
- 学習者ごとの補正：直近20回の正解の「回答時間 ÷ 基準」の中央値を掛ける（0.7〜1.6倍。5回たまるまでは補正しない）

## 覚えた（クローズ）とする条件

| 最初の結果 | クローズの条件 | 目安 |
|---|---|---|
| good（初回に速く正解） | 翌日以降の出題日に、もう一度正解 | 2回・翌日 |
| hard（初回は遅い正解） | 日を変えて合計3回正解（出題の間隔は 1日 → 3日） | 3回・約4日 |
| again（一度でも間違えた） | 間違えた日の翌日から、日を変えて3回正解（間隔は 1日 → 1日 → 3日） | 3回・約5日 |

- 数えるのは「出題日が来た日の、その日に間違えていない正解」だけ。同じ日の2回目以降の正解や、出題日より前の正解は数えない
- 間違えたら、それまでの回数は0に戻り、3回のコースで翌日から数え直す
- クローズした問題は今日の想起に出さない。章末演習・総合演習・練習で出て間違えたら、クローズを解いて学び直す

## 同じ日の再出題

- 節のすぐ確認で間違えたら、次のページ（最後の項目ならまとめのページ）の右ページにもう一度出す。間違えたページに戻っても、その場では解き直させない
- 演習・今日の想起で間違えたら、3問あとにもう一度出す
- どちらも、同じ問題は1回の中で3回まで。同じ日の再出題の正解は、クローズの回数に数えない（hard として記録する）

## 何を出すか（システムが組み立てる）

| 場面 | 出す問題 |
|---|---|
| 節のページを開いたとき | 出題日が来た問題があれば、最初に「扉」のページを出す。右ページに、この節の出題日が来た問題（一度正解したもの）と、ほかの節の出題日が来た問題を最大2問 |
| 項目のページ | 右ページにその項目のすぐ確認1問（予告問題）。一度正解した問題は「正解済み」と出題日だけを表示し、「練習で解く」（記録しない）で解き直せる |
| 今日の想起（ホーム） | 出題日が来た問題を、出題日の古い順・間違えた回数の多い順に最大10問。同じ節が続かないように並べる |
| 章末演習・総合演習 | まだ解いていない問題 → 出題日が来た問題 の順に最大10問。覚えた問題と出さない問題は出さない |
| 模擬試験 | 章末演習と総合演習から無作為に `questionCount` 問。考える時間なし・正誤を出さない・記録しない。制限時間 `minutes` 分 |

## 伏せ字（2回目に開いた項目）

- 節を開いた時点で、すぐ確認に一度正解している項目は、左ページの本文のキーワードを伏せ字にする。押すと開く。「すべて開く」もある
- 伏せるのは本文の `<strong>`。図（`figure`）・コード（`pre`）・前提の説明（`sk-premise`）の中と、「何か：」のように「：」で終わる見出し語は伏せない
- 開いた伏せ字は、その節を開いているあいだは開いたまま。節を開き直すと、また伏せる
- 伏せ字は記録しない（押した・押さないで判定は変わらない）

## 次の節へ進む条件

- その節のすぐ確認（出さない問題を除く）すべてに一度正解したら、「次の節」ボタンが開く。一度正解した記録は残るので、日をまたいでもやり直しは要らない
- 章の最後の節では、「次へ」で章末演習に進む
- 目次からは、どの節もいつでも開ける

## もう出さない（除外）

- 出題中のどの段階でも、問いの右上の「この問題はもう出さない」で除外できる（答える前でもよい）
- 除外した問題は、すぐ確認・今日の想起・演習・模擬試験のどれにも出さない。次の節へ進む条件と進捗の分母からも外す
- ⚙ 設定の「出さない問題」に一覧で出し、そこから戻せる。学習履歴の書き出しに一覧（場所と問題文）を含める。教材を作り直すときに、問題を削るか直すかの材料にする

## 進捗

- 覚えた割合（上部バーとホーム）＝ 覚えた（クローズした）問題 ÷ 出題する問題（すぐ確認＋章末演習＋総合演習 − 出さない問題）。小数点以下は切り捨て
- 章カードには、節の完了数と、その章の問題（すぐ確認＋章末演習）のうち覚えた数を出す

## 画面

| 画面 | 内容 |
|---|---|
| ホーム | 1段目：今日の想起（黄色のカード。今日の問題の数と「今日の問題を解く」）と覚えた割合。2段目：続きから学習（節名・すぐ確認の丸・「学習を再開」）。3段目：目次（番号付きの章カード。読了／学習中／未着手）。4段目：総合演習・模擬試験・この教材のゴール |
| 節のページ（見開き） | 上：「☰ 目次」（左からスライド。「‹ ホーム」、章ごとの節と「章末演習へ」、最後に「総合演習へ」）、章名、節番号の四角と節名、読了目安・問題数の札、「次へ進むまで あと N 問」。その下にページの札（扉・項目ごとの番号・まとめ。✓ 正解済み・↻ 今日間違えた・紫の枠が開いているページ）。本は1項目1見開きで、左ページ＝教科書（項目の説明、2回目は伏せ字）、右ページ＝問題集（その項目の問題。タブに「問題 ・ 形式」、カードに「1-2 ①」）。右ページは読み進めても画面に残る。扉：左にこの節で学ぶこと、右に出題日が来た問題。まとめ：左に要点・参考出典・メモ、右に項目ごとの状態・残っているもう一度の問題・次の節へのボタン。本の下に前後のページへのボタン。幅 860px 以下では左右のページを縦に並べる |
| 演習 | 今日の想起・章末演習・総合演習・模擬試験で共通。上に戻るボタン・演習名・「N / M 問目」・経過時間。1問ずつ、カードの左上に形式のタブ。右に「この回の問題」のマス（○ 正解・× 不正解・↻ もう一度・紫の枠がいま解いている問題） |
| 設定（右上の ⚙） | 出さない問題（戻せる）、学習履歴の書き出し・読み込み・削除 |

- 問題の状態の表示：未出題（灰）・今日出す（黄）・次は M/D（青）・覚えた（緑）・出さない（点線）
- 演習の画面と節のページでは、選択肢を数字キーでも選べる。Enter で次へ（節のページでは「読んだので答える」と「次のページへ」）。節のページは ← → でページをめくれる
- 正解で紙吹雪。節のすぐ確認に全問正解・演習の1回目に全問正解・模擬試験の合格で大きな紙吹雪。OS で「視差効果を減らす」が有効なときは出さない
- 用語・本文・問題を検索でき、結果から節の該当項目へ移動する

## 保存

- 学習履歴はブラウザのローカルストレージに、キー `study-kit:{meta.id}` で保存する。外部の CDN やライブラリは読み込まない
- ⚙ 設定の「書き出す／読み込む」で JSON にして控えを取れる。読み込みは同じ教材IDで、同じ形式（`version`）の履歴だけ受け付ける

```json
{
  "version": 3,
  "contentId": "k8s-practical-20261005",
  "questions": {
    "q-ch1-s1-01": { "status": "learning", "track": "standard", "streak": 1, "due": "2026-10-16", "lastCounted": "2026-10-15", "wrongDay": "2026-10-14", "everCorrect": true, "attempts": 3, "lapses": 1, "lastAnswered": "2026-10-15" },
    "q-ch1-s1-02": { "status": "closed", "track": "fast", "streak": 2, "closedOn": "2026-10-15", "everCorrect": true, "attempts": 2 },
    "q-ch1-s2-01": { "status": "excluded", "prevStatus": "new", "attempts": 0 }
  },
  "rtRatios": [0.62, 0.8, 1.1],
  "memos": {},
  "lastSectionId": "ch1-s2",
  "stats": { "answered": 12, "correct": 10 }
}
```

- `status`：`new`（未出題）／`learning`（覚えている途中）／`closed`（覚えた）／`excluded`（出さない）
- `track`：`fast`（2回でクローズ）／`standard`（3回でクローズ）。`streak` は日を変えて数えた正解の回数
- 書き出したファイルには、確認用に `excludedQuestions`（出さない問題の場所と問題文）を加える
- `version` が 3 より前の履歴は形が違うため引き継がない

## 動作確認

URL に `?today=YYYY-MM-DD` を付けると、その日付として動く（上部バーに「検証用の日付」と出る）。日をまたぐ出題とクローズの確認に使う。
