# 学習エンジンの仕様（assets/template.html）

教材を作るときに template.html を書き換える必要はない。この文書は、学習者に使い方を説明するときと、template.html を直すときに読む。template.html を変えたら、必ずこの文書も合わせる。

## 根拠にした研究知見

| 知見 | 設計への反映 | 出典（**未確認**：一次文献で確認してから確定する） |
|---|---|---|
| テスト効果：読み返すより問題を解くほうが記憶に残る | 項目を説明するたびに、すぐ確認を1問解かせる | Roediger, H. L., & Karpicke, J. D. (2006). Test-enhanced learning. *Psychological Science*, 17(3), 249–255. |
| 生成効果：答えを見るより、自分で思い出して答えを出すほうが記憶に残る | すぐ確認で間違えたときは正解を見せず、本文を読み直して自力で解き直させる | Slamecka, N. J., & Graf, P. (1978). The generation effect: Delineation of a phenomenon. *Journal of Experimental Psychology: Human Learning and Memory*, 4(6), 592–604. |
| 習得学習：前の単元を習得してから次へ進むと、つまずきが積み重ならない | 節のすぐ確認に全問正解するまで、次の節へ進むボタンを開かない | Bloom, B. S. (1968). Learning for mastery. *Evaluation Comment*, 1(2). |

（2026-10-13 にユーザーの判断で、節の問題の「日をまたいだ再出題（段階1〜3）」を廃止した。章末演習・総合演習の間違いは復習リストで解き直す）

## 画面

ダーク基調。上部バーに教材名（`meta.series` があれば上に小さく）、用語・問題の検索、全体の進捗（ホーム以外）、⚙ 設定を置く。

| 画面 | 内容 |
|---|---|
| ホーム | 左：「続きから学習」カード（最後に開いた節。すぐ確認の正解数・読了目安・「学習を再開」「問題だけ解く」）、目次（章カード：完了／学習中／未着手、節の完了数、章末演習の正解数）、演習（総合演習・模擬試験）。右：全体の進捗（％・完了した節・問題の正答率）、復習リスト（「まとめて解く」）、この教材のゴール |
| 節のページ | 左：目次（幅 1100px 未満では「☰ 目次」で左からスライド）。中央：節の見出し・読了目安・すぐ確認の数・前提の節、項目ごとに「説明 → すぐ確認」、参考出典、前後の節へのボタン。右：本文とすぐ確認の対応（正解数・次へ進むまでの残り・項目ごとの状態）、この節の要点、メモ |
| 演習 | 章末演習・総合演習・復習リスト・模擬試験で共通。上：戻るボタン、何の演習か、何問目か、経過時間（模擬試験は残り時間）。中央：1問ずつ。右：問題一覧（番号のマス）、節ごと（章末演習）または章ごとの正答 |
| 設定（右上の ⚙） | 学習履歴の書き出し・読み込み・削除 |

- 「学習を始める」ボタンで一方的に出題しない。学習者が目次から読みたい節（どの章からでもよい）を選ぶ
- 節のページの「読んで解く／問題だけ解く」で、説明を隠してすぐ確認だけにできる
- 検索は、項目の見出し・本文・すぐ確認・要点・演習の問題文を対象にする。結果を押すと、その節の該当項目まで移動して光らせる

## 節のページ：読んだらすぐ確認

1. 項目ごとに、説明（見出し・本文・図）のすぐ下に「⚡ すぐ確認」を1問置く。例題の項目の後ろは「類題」と表示する
2. すぐ確認は、答えた瞬間に正誤を出す（選択・○×は押した瞬間、入力・並べ替えは「答え合わせ」で）
3. **正解**：紙吹雪を出し、解説と「次の項目へ ↓」を出す
4. **不正解**：正解も解説も見せない。「どこで間違えたかを本文で確かめてから、もう一度解いてみましょう」と、「📖 その項目を読み直す」「↻ もう一度解く」を出す。解き直しでは選択肢の順番をシャッフルする。`hint` があれば「💡 ヒント」で出す
5. 一度正解したすぐ確認は、次に開いたとき「✓ 正解済み」と解説を出す。「もう一度解いてみる（練習）」で解き直せるが、練習で間違えても記録は正解のまま
6. 右の「本文とすぐ確認の対応」は、いま読んでいる項目を枠で強調し、項目ごとに 未回答／正解／不正解 を出す

## 次の節へ進む条件（ゲート）

- 節のすぐ確認に **全問正解** すると、その節は完了になり、「次の節」ボタン（最後の節では「章末演習」）が押せるようになる
- 全問正解するまでボタンは「🔒」付きで押せず、「あと N 問」と出す
- 全問正解した瞬間に、画面両下から大きな紙吹雪を出す
- 目次からは、どの節もいつでも開ける（鍵がかかるのは「次の節」ボタンだけ）。章末演習・総合演習もいつでも解ける

## 演習（章末演習・総合演習・復習リスト・模擬試験）

| 種類 | 始める場所 | 出す問題 |
|---|---|---|
| 章末演習 | 目次の「第N章 章末演習へ」、章の最後の節の「次へ」 | その章の `exercise` から10問。未解答 → 前回不正解 → 正解済み の順 |
| 総合演習 | ホームの「演習」、目次の「総合演習へ」 | `finalExam` から10問。順番の決め方は章末演習と同じ |
| 復習リスト | ホームの「復習リストをまとめて解く」 | 復習リストの問題から10問 |
| 模擬試験 | ホームの「演習」（`meta.exam` があるときだけ） | 章末演習と総合演習の全問題からランダムに `questionCount` 問 |

- 1問ずつ答える。答えた瞬間に正誤・正解・解説と「📖 教科書で確認する」（`refs` の節・項目へ移動）を出す
- 不正解の問題は自動で復習リストに入る。正解した問題も「⚑ あとで復習」で復習リストに入れられる
- 解答後に「次の問題へ」（Enter）。選択肢と○×は数字キーでも選べる
- 2回目以降の出題では、選択肢と並べ替え項目の順番をシャッフルする
- 結果画面：正解数、間違えた問題の正解・解説・教科書へのリンク、「続けて解く（残り N問）」、章末演習なら次の章へのボタン。全問正解なら大きな紙吹雪

### 模擬試験

- 制限時間 `minutes` 分。途中で正誤を出さず、時間切れか「採点して終了」で採点する
- 結果に正答率、`passingRate` があれば合否、間違えた問題の正解と解説を出す
- 学習履歴には記録しない

## 復習リスト

- 章末演習・総合演習で **最後に答えたときに間違えた問題** と、「あとで復習」に登録した問題
- 正解すると（演習でも復習リストでも）、リストから外れる。「あとで復習」の登録も外れる
- すぐ確認の問題は入らない（節の中で解き直すため）

## 完了と進捗

| 単位 | 完了条件 |
|---|---|
| 節 | すぐ確認にすべて正解 |
| 章 | 含まれる節がすべて完了（章カードに「完了」） |

- 進捗率（上部バーとホーム）= 正解済みの問題 ÷ 全問題。正解済みは「正解したすぐ確認」と「最後に正解した章末演習・総合演習の問題」。全問題は すぐ確認＋章末演習＋総合演習。小数点以下は切り捨て
- 問題の正答率（ホーム）= 正解した回答 ÷ すべての回答（すぐ確認・演習。模擬試験は含めない）
- 読了目安：節の `minutes`。ないときは本文の文字数 ÷ 400 字/分 で見積もる（切り上げ）

## 演出

- ゲームっぽい演出として、正解で紙吹雪（クラッカー）、不正解で問題の枠が揺れる。節の全問正解・演習の全問正解・模擬試験の合格で、画面両下から大きな紙吹雪
- OS で「視差効果を減らす」が有効なときは、紙吹雪とアニメーションを出さない
- レベルや XP は使わない（進捗率で進み具合を見せる）

## 保存

- 学習履歴はブラウザのローカルストレージに、キー `study-kit:{meta.id}` で保存する
- 右上の ⚙ 設定の「書き出す／読み込む」で JSON にして控えを取れる。読み込みは同じ教材IDで、同じ形式（`version`）の履歴だけ受け付ける
- 外部の CDN やライブラリ、フォントは読み込まない（オフラインで動く）

## 保存する学習履歴の形

```json
{
  "version": 2,
  "contentId": "k8s-practical-20261005",
  "checks": { "q-ch1-s1-01": "ok", "q-ch1-s1-02": "ng" },
  "questions": {
    "q-ch1-ex-03": { "result": "ng", "flagged": false, "attempts": 1, "lastAnswered": "2026-10-13" },
    "q-ch1-ex-04": { "result": "ok", "flagged": true, "attempts": 2, "lastAnswered": "2026-10-13" }
  },
  "memos": { "ch1-s1": "localhost で通信できるのは同じ Pod の中だけ" },
  "lastSectionId": "ch1-s2",
  "stats": { "answered": 15, "correct": 12 }
}
```

- `checks`：すぐ確認の問題ID → `ok`（一度でも正解）／`ng`（間違えたまま）。記録がなければ未回答
- `questions`：章末演習・総合演習の問題ID → 最後の結果（`result`）、「あとで復習」（`flagged`）、回答回数、最後に答えた日
- `version` が 1 の古い履歴（段階1〜3の再出題を持っていた形式）は引き継がない

## 動作確認

`examples/` の教材HTMLをブラウザで開いて確かめる。日付で動きが変わる仕組みはないので、日付の指定は不要。
