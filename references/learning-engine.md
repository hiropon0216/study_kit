# 学習エンジンの仕様（assets/template.html）

教材を作るときに template.html を書き換える必要はない。この文書は、学習者に使い方を説明するときと、template.html を直すときに読む。

## 根拠にした研究知見

| 知見 | 設計への反映 | 出典（**未確認**：一次文献で確認してから確定する） |
|---|---|---|
| テスト効果：読み返すより問題を解くほうが記憶に残る | アウトプット多め（3：7） | Roediger, H. L., & Karpicke, J. D. (2006). Test-enhanced learning. *Psychological Science*, 17(3), 249–255. |
| 過剰学習の収穫逓減：正解できる問題を繰り返しても効果はほぼ増えない | 初回正解でクローズし、二度と出さない | Rohrer, D., Taylor, K., Pashler, H., Wixted, J. T., & Cepeda, N. J. (2005). The effect of overlearning on long-term retention. *Applied Cognitive Psychology*, 19(3), 361–374. |
| 分散効果：間隔を空けて思い出すほうが定着する | 誤答した問題は日をまたいで再出題する | Cepeda, N. J., Pashler, H., Vul, E., Wixted, J. T., & Rohrer, D. (2006). Distributed practice in verbal recall tasks. *Psychological Bulletin*, 132(3), 354–380. |
| 連続再学習：日を分けて複数回正解させると長期の定着が伸びる | 誤答した問題は、日をまたいだ2回の正解でクローズする | Rawson, K. A., Dunlosky, J., & Sciartelli, S. M. (2013). The power of successive relearning. *Educational Psychology Review*, 25(4), 523–548. |

## 画面の構成

| 画面 | 内容 |
|---|---|
| ホーム | 教材のゴール、状態ごとの問題数、「復習」カード（今すぐ解ける問題か待ちの問題があるときだけ）、ステージマップ（節カードに問題1問ずつの丸） |
| 節のページ | 先頭に問題の状態の早見、本文、末尾に「この節の問題」カード（問題に挑戦ボタン）、参考出典 |
| 問題 | 1問ずつ解く。下に「中断してホームへ」 |
| 結果 | 正解数、クローズ数、進捗率の変化、間違えた問題の解説、次の行動のボタン |
| 設定（右上の ⚙） | 学習履歴の書き出し・読み込み・削除 |

- 「学習を始める」ボタンはない。学習者はステージマップで読みたい節（どの章からでもよい）を選ぶ
- 時間の目安や設定はない

## セッション

- ページを開いてから閉じるまでが1セッション。段階1（同じセッションの最後の再出題）はこの単位で判定する
- 問題は「1回分」ずつ解く。1回分は次の4種類で、どれも学習者がボタンを押したときだけ始まる

| 種類 | 始める場所 | 出す問題 |
|---|---|---|
| 節 | 節のページの「未挑戦の問題に挑戦」 | その節の未挑戦の問題 |
| 総合演習 | ホームの BOSS カード（全章クリア後） | 総合演習の未挑戦の問題から、並び順に最大10問（問題数が多いため1回分を区切る） |
| 復習 | ホームの「復習」カード（全体）、節のページの「今すぐ解ける問題」（その節だけ） | 今すぐ解ける問題 |
| 再挑戦 | 結果画面の「今すぐ再挑戦」 | その回で間違えた問題 |

## 問題の状態の見せ方

問題ごとに次の4つの状態を持ち、番号入りの丸1つで1問を表す。ステージマップの節カード・節のページ・総合演習で同じ表示を使う。

| 状態 | 丸の色 | 意味 |
|---|---|---|
| 未挑戦 | 灰（枠のみ） | まだ1度も解いていない |
| 今すぐ解ける | 橙（点滅） | 段階1（同じセッション内の再挑戦）か、再出題日を迎えた段階2・3 |
| 待ち | 赤（止まれ） | 再出題日がまだ来ていない。いつから解けるかを「⏳ 待ち 2（10/9から）」のように出す |
| クリア | 緑（✓） | クローズ済み |

- ホームの「復習」カードに、今すぐ解ける問題数と、次に解けるようになる日ごとの問題数（例「明日（10/6）2問・10/9 1問」）を出す
- 回答のたびに、その問題が次にいつ出るか（すぐ再挑戦できる／○日以降／クリア）を解説の下に出す
- 結果画面に、その回で答えた問題の状態の内訳を出す
- 誤答した問題の流れ（すぐ再挑戦 → 翌日以降 → そこで正解した3日後以降、翌日以降の2回に続けて正解でクリア）を、待ちの問題があるときに一文で添える

- 「中断してホームへ」で途中でやめられる。答えなかった問題はそのままの状態で残る

## 節の進め方

インプット（本文を読む）→ アウトプット（問題を解く）の順に進める。

1. 節のページは、本文 →「この節の問題」カード → 参考出典 の順に並べる。ページの先頭には問題の状態の早見（丸と内訳）と「問題へ ↓」のリンクだけを置く
2. 本文を読み終えたら、末尾の「この節の問題」カードから問題に挑戦する
3. 1問ごとに正誤と解説、教科書の該当節へのリンクを出す
4. 結果画面に、誤答・不明だった問題の一覧と教科書へのリンクを出す。間違えた問題があれば「本文を読み直す」、全問正解なら次の節へのボタンを出す

（設計当初は事前テスト効果を根拠に「先に問題を解く」順にしていたが、2026-10-05 にユーザーの判断でインプット → アウトプットの順に変えた）

## クローズの条件

初回で正解した問題は、その場でクローズする。クローズした問題は二度と出さない。

誤答・不明だった問題：

| 段階 | タイミング | 正解したとき | 誤答・不明のとき |
|---|---|---|---|
| 0 | その場 | ― | 解説と教科書の該当節へのリンクを出し、段階1へ |
| 1 | 同じセッションの最後 | 段階2へ（クローズしない） | 解説を再表示し、段階2へ |
| 2 | 誤答した日の翌日以降の最初のセッション | 段階3へ | 段階0に戻る |
| 3 | 段階2で正解した日の3日後以降の最初のセッション | クローズ | 段階0に戻る |

- 段階1を受けずにセッションが終わった（ページを閉じた）問題は、段階2として扱う
- 日付は端末のローカル日付で判定する（10/6 に段階2で正解 → 10/9 以降に段階3）
- 2回目以降の出題では、選択肢と並べ替え項目の順番をシャッフルする
- 「不明」は不正解と同じ扱い

## 完了の判定

| 単位 | 完了条件 |
|---|---|
| 節 | その節の問題がすべてクローズ |
| 章 | 含まれる節がすべて完了 |
| 総合演習 | すべての章が完了すると出題される。クローズ条件は上と同じ |
| 教材 | 総合演習の問題がすべてクローズ |

ホームに章ごとの「クリア○問／全○問」を出す。

## 進捗率

- 進捗率 = クローズ済みの問題数 ÷ 全問題数（節の問題＋総合演習）。小数点以下は切り捨て
- 画面上部のバーに常に出す。結果画面には、その回の前後の進捗率（例 0% → 16%）を出す

## ゲーム要素（クローズの判定には使わない）

| 要素 | 内容 |
|---|---|
| 連続学習日数 | 問題を解いた日が続いた日数（🔥）。上部バーに出す |
| コンボ | セッション内の連続正解数。2連続から表示 |
| ステージマップ | ホームで章を WORLD、節を STAGE のノードとして並べる。総合演習は BOSS（全章クリアで解放） |
| 演出 | 正解で紙吹雪（クラッカー）、クローズしたら新しい進捗率が浮き上がる、誤答でカードが揺れる、節の全問正解・教材クリアで画面両下から大きな紙吹雪 |

レベルと XP は使わない（進捗率で進み具合を見せる）。

- OS で「視差効果を減らす」が有効なときは、紙吹雪とアニメーションを出さない
- キーボード：数字キーで選択肢を選び、Enter で回答・次へ

## 模擬試験（`meta.exam` があるときだけ）

- 全問題（各節の問題＋総合演習）から `questionCount` 問をランダムに選び、`minutes` 分の制限時間で解く
- 1問ずつ答え、途中で正誤は出さない。時間切れで自動採点する
- 結果に正答率、`passingRate` があれば合否、間違えた問題の解説を出す
- 学習履歴（クローズの判定）には記録しない

## 保存

- 学習履歴はブラウザのローカルストレージに、キー `study-kit:{meta.id}` で保存する
- 右上の ⚙ 設定の「書き出す／読み込む」で JSON にして控えを取れる。読み込みは同じ教材IDの履歴だけ受け付ける
- 外部の CDN やライブラリは読み込まない

## 保存する学習履歴の形

```json
{
  "version": 1,
  "contentId": "k8s-practical-20261005",
  "settings": {},
  "game": { "activeDays": ["2026-10-05"], "bestCombo": 2 },
  "questions": {
    "q-ch1-s1-01": { "status": "closed", "attempts": 1, "lastAnswered": "2026-10-05" },
    "q-ch1-s1-03": { "status": "learning", "stage": 2, "due": "2026-10-06", "sessionId": "s1791128368470", "attempts": 2, "lastAnswered": "2026-10-05" }
  }
}
```

`status` は `new`（未出題。記録なしも同じ）／`learning`（再学習中）／`closed`（学習済み）。

## 動作確認

URL に `?today=YYYY-MM-DD` を付けると、その日付として動く（画面上部に「検証用の日付」と出る）。日をまたぐ再出題の確認に使う。
