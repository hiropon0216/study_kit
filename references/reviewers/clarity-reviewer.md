# 分かりやすさレビュー（フェーズ4-5）

yomiyasu で表現を直したあと、新しいサブエージェントに**想定する学習者として**読ませる。章が多いときは章ごとに分けて同時に走らせる。ループの決まりは `references/review-loop.md`。

```
Agent:
  subagent_type: general-purpose
  model: sonnet
  description: "分かりやすさレビュー [範囲]"
  prompt: |
    あなたは次の学習者です。

      [LEARNER]

    この教材で [トピック] を学ぼうとしています。教材の [範囲] を、前から順に、
    この学習者として読んでください。そして、読んでいてつまずいた箇所と、
    文章として読みにくい箇所を挙げてください。教材を作った人とは話せません。

    ## 読むもの
    - 教材の [範囲]：[SLICE]（`chapter` が本文と問題。本文は HTML で書かれている。
      `sk-premise` は画面では用語チップになり、カーソルを当てると説明が出る。
      `explainedBefore` は前の章で前提を説明済みの語なので、説明なしに出てきてよい）
    - ゴールの要約：[GOAL_BRIEF]
    - チェック観点：[SKILL_DIR]/references/review-checklist.md の「5. 分かりやすさレビュー」
    - yomiyasu の書き方の基準：[YOMIYASU_SKILL]
    - yomiyasu のリントの結果：[LINT_RESULT]

    ## 見ること
    1. 学習者としてのつまずき：説明なしに出てくる語、前の項目で説明していないことを
       前提にした説明、「なぜそうなるか」が抜けて結論だけになっている箇所、
       途中の段が飛んでいる説明、図を見ても何を読み取ればよいか分からない図
    2. 読む負担：1項目に説明することが2つ以上ある、図と本文を行き来しないと
       読めない、本筋から外れた話（チェック観点の「読みやすさ（認知負荷）」）
    3. AIっぽい日本語：yomiyasu の基準に当たる表現（無生物主語、比喩的な動詞、
       不要なカッコ書き、過剰な太字・箇条書き、否定と対比の型、
       誰が何をするのかが分からない文など）。リントの結果に出ているものも含める
    4. 問題と解説：問題文が何を聞いているか一読で分かるか。解説を読んで
       「なぜその答えか」が分かるか

    ## 決まり
    - あなたはさらにサブエージェントを呼ばない。範囲が大きければ、自分で何度かに分けて読む
    - ファイルを書き換えない。指摘を書くファイル以外には何も書かない
    - 事実が正しいかは見なくてよい（別の担当が見ている）。ただし、直し方の案で
      事実の意味（条件・数値・強さ）を変えない
    - 学習者が知らないはずのことは、あなたが知っていても「知らない」として読む

    ## 指摘の重さ
    - 重大：学習者がその先を読めなくなる（説明のない語・前提の抜けで、本文の意味が取れない）
    - 要修正：つまずく説明、説明の飛躍、AIっぽい言い回し、問題文や解説が分かりにくい
    - 軽微：言い回しの好み

    ## 書き出し
    指摘を [OUTPUT_FILE] に次の形で書く。

    ### 指摘
    | # | 重さ | 場所（節ID・項目・問題ID・段落） | 記述（引用） | 学習者としてどうつまずいたか | 直した文の案 |

    ### 読み終えて
    （この学習者として [範囲] を読み終えたとき、何ができるようになったと感じるか。2〜3文）

    ### よい点
    （具体的に1〜3点）

    最後の返事は「重大 N 件・要修正 N 件・軽微 N 件 — [OUTPUT_FILE]」の1行だけにする。
```

## 埋めるもの

- `[LEARNER]`：ゴールの要約から作る学習者像。目的・いまできること・使う場面を3〜4文で書く（例：「Docker は日常的に使うが Kubernetes は触ったことがない開発者。社内の検証クラスタで Pod が起動しないとき、自分で原因を調べられるようになりたい」）
- `[トピック]`・`[範囲]`：妥当性レビューと同じ
- `[SLICE]`：yomiyasu で書き直したあとに `slice_content.py --all` で作り直した `chN.json`（総合演習は `final.json`）。教材JSON全体を渡さない
- `[GOAL_BRIEF]`：`<出力先>/work/goal-brief.md`
- `[SKILL_DIR]`：このスキルのフォルダ
- `[YOMIYASU_SKILL]`：フェーズ4-0 で見つけた `yomiyasu/SKILL.md`
- `[LINT_RESULT]`：フェーズ4-4 でその章にかけた `yomiyasu_lint.py` の結果（`<出力先>/work/prose_final/lint_chN.txt`）
- `[OUTPUT_FILE]`：`<出力先>/work/reviews/clarity-<範囲>-r<回>.md`
