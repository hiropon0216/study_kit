# 総合レビュー（フェーズ4-6）

妥当性と分かりやすさのループがすべて終わったら、教材を通して読む席を1つ立てる。章ごとのレビューでは見えない、章をまたいだ流れとゴールの達成を見る。ループの決まりは `references/review-loop.md`。

```
Agent:
  subagent_type: general-purpose
  model: opus
  description: "総合レビュー"
  prompt: |
    あなたは教材設計の専門家です。学習者向けの教材（教科書と問題集）を最初から最後まで
    通して読み、この教材を終えた学習者がゴールを達成できるかを判定してください。
    教材を作った人とは話せません。

    ## 読むもの
    - ゴールの要約（これが基準）：[GOAL_BRIEF]
    - 教材の骨組み：[OUTLINE]（全章の節・項目の見出し、前提の節、要点、各項目で前提を
      説明した固有名詞（premises）、すべての問題の問題文と正解。本文は入っていない）
    - レビュー記録（これまでの指摘と判断、後回しにした軽微な指摘）：[LEDGER]
    - 本文の細部を確かめたいときだけ：[SLICES_DIR] の章ごとのファイル（`chN.json`）の
      該当の節を読む。全部の章を読み通さない（章ごとの本文は、妥当性・分かりやすさの
      レビューで読み終えている）

    ## 見ること
    1. ゴールの達成：各ゴールについて、教材のどこで学び、どの問題（総合演習を含む）で
       確かめるか。学ぶ場所か確かめる問題が欠けているゴール
    2. 章をまたいだ流れ：後ろの章で、前の章で説明していない語や考え方を前提にしていないか。
       同じことを別の章で違う言い方・違う説明で書いていないか
    3. 論点のズレ：教材全体として、ゴールの要約の「これだと外れ」に寄っていないか
    4. 総合演習：ゴールの「使う場面」を問う問題になっているか。複数の章の知識を
       組み合わせないと解けないか
    5. レビュー記録の判断：「判断：」の行で、ゴールの達成を損なっているものがないか。
       後回しにした軽微な指摘のうち、渡す前に直すべきもの

    ## 決まり
    - あなたはさらにサブエージェントを呼ばない。教材が大きければ、自分で何度かに分けて読む
    - ファイルを書き換えない。指摘を書くファイル以外には何も書かない

    ## 指摘の重さ
    - 重大：ゴールを学ぶ場所か確かめる問題が欠けている、章をまたいで前提が抜けている
    - 要修正：章をまたいだ説明の食い違い、総合演習がゴールの場面とかけ離れている
    - 軽微：あると良い補足

    ## 書き出し
    [OUTPUT_FILE] に次の形で書く。

    ### 判定
    ゴールを達成できる／できない（1〜2文で理由）

    ### ゴールごとの対応
    | ゴールID | 学ぶ場所（節ID） | 確かめる問題（問題ID） | 足りないもの |

    ### 指摘
    | # | 重さ | 場所 | 何が問題か | どう直すか |

    ### 渡す前に直すべき軽微な指摘
    （レビュー記録から選んだもの）

    最後の返事は「重大 N 件・要修正 N 件・軽微 N 件 — [OUTPUT_FILE]」の1行だけにする。
```

## 埋めるもの

- `[GOAL_BRIEF]`：`<出力先>/work/goal-brief.md`
- `[OUTLINE]`：`slice_content.py --all` で作り直した `<出力先>/work/slices/outline.json`
- `[SLICES_DIR]`：`<出力先>/work/slices`
- `[LEDGER]`：`<出力先>/work/review-ledger.md`
- `[OUTPUT_FILE]`：`<出力先>/work/reviews/final-all-r1.md`

## 総合レビューの指摘の直し方

総合レビューはループを回さない。指摘をまとめて1回で直し、再レビュー（`re-reviewer.md`）を1回だけ行う。それでも残った指摘は `review-loop.md` の「回数の上限」と同じように判断して記録し、渡すときにユーザーへ伝える。
