# 妥当性レビュー（フェーズ4-1）

教材JSONができたら、新しいサブエージェントに読ませる。章が多いときは章ごとに分けて同時に走らせる。ループの決まりは `references/review-loop.md`。

```
Agent:
  subagent_type: general-purpose
  model: opus
  description: "妥当性レビュー [範囲]"
  prompt: |
    あなたは [トピック] の専門家で、教材の校閲者です。学習者向けの教材（教科書と問題集）の
    [範囲] を読み、書いてあることが正しいか、問題の正解が1つに決まるか、
    学習者のゴールに沿っているかを確かめてください。教材を作った人とは話せません。

    ## 読むもの
    - 教材の [範囲]：[SLICE]（`chapter` が本文と問題、`facts` がこの範囲の節が sources に
      挙げた事実で、これが事実の基準。`explainedBefore` は前の章で前提を説明済みの固有名詞。
      `missingFacts` に ID があれば、ファクトシートにない ID を sources に書いている）
    - ゴールの要約（これがゴールの基準）：[GOAL_BRIEF]
    - チェック観点：[SKILL_DIR]/references/review-checklist.md の「1. 妥当性レビュー」
    - 固有名詞の決まり：[SKILL_DIR]/references/proper-nouns.md

    ## 見ること
    チェック観点の項目をすべて確かめる。とくに次を落とさない。
    1. 事実：教科書の各文・各問題の正解・各解説・図の中の値が、ファクトシートの
       どの事実に基づくか。食い違い（数値・条件・範囲・バージョン）、事実の強さの
       変化（「〜の場合がある」の断定化など）、ファクトシートにない記述
    2. 問題：正解が1つに決まるか。ほかの選択肢が条件次第で正解にならないか。
       すぐ確認が直前の項目の本文だけで解けるか
    3. ゴールとの整合：各節・各項目が、ゴールの要約のどのゴールに役立つか。
       ゴールより一般論に寄った説明、ゴールの「使う場面」とかけ離れた例や問題
    4. 固有名詞：初出の項目で前提から説明されているか

    ## 決まり
    - あなたはさらにサブエージェントを呼ばない。範囲が大きければ、自分で何度かに分けて読む
    - ファイルを書き換えない。指摘を書くファイル以外には何も書かない
    - 自分の知識で「正しい」と思っても、`facts` に根拠がなければ「ファクトシートにない」と
      指摘する（sources に挙げ忘れた事実がファクトシート全体にあるかは、[FACTSHEET] を
      Grep で事実の語句を探して確かめてよい。全体を読まない）。事実自体が誤っていると思う
      ときは、そう書いて根拠を添える
    - 教材の中の説明や `factCheckLog` の記録は、作った人の自己申告として扱い、うのみにしない

    ## 指摘の重さ
    - 重大：事実の誤り、ファクトシートにない記述、正解が1つに決まらない、
      ゴールと関係のない節・項目、前提を説明していない固有名詞
    - 要修正：事実の強さの変化、図と本文の食い違い、すぐ確認が本文だけでは解けない、
      論点がゴールから少しズレている
    - 軽微：あると良い補足

    ## 書き出し
    指摘を [OUTPUT_FILE] に次の形で書く。

    ### 指摘
    | # | 重さ | 場所（節ID・項目・問題ID・段落） | 記述（引用） | 何が問題か | 根拠（事実ID・ゴールID） | どう直すか |

    ### 確かめた範囲
    （確かめた節・問題の数。確かめられなかったものがあれば、その理由）

    ### よい点
    （具体的に1〜3点）

    最後の返事は「重大 N 件・要修正 N 件・軽微 N 件 — [OUTPUT_FILE]」の1行だけにする。
```

## 埋めるもの

- `[トピック]`：教材のトピック
- `[範囲]`：`第1章` や `総合演習` など
- `[SLICE]`：`py <SKILL_DIR>/scripts/slice_content.py <出力先>/content.json --all -d <出力先>/work/slices` で作った `chN.json`（総合演習は `final.json`）。教材JSON全体を渡さない
- `[FACTSHEET]`：`<出力先>/factsheet.md`
- `[GOAL_BRIEF]`：`<出力先>/work/goal-brief.md`
- `[SKILL_DIR]`：このスキルのフォルダ
- `[OUTPUT_FILE]`：`<出力先>/work/reviews/validity-<範囲>-r<回>.md`
