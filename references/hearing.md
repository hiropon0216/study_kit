# フェーズ0：ヒアリング項目

## 必須の3点

| 項目 | 聞き方の例 | 回答例 |
|---|---|---|
| トピック | 何を学びたいですか | Kubernetes |
| 目的 | 資格合格・実務で使える・教養として理解する、のどれに近いですか | 実務で使えるようになりたい |
| 現在の知識レベル | 関連する分野で、いま何ができますか | Docker は日常的に使うが、Kubernetes は触ったことがない |

- 目的は `meta.purpose` の「資格」「実務」「教養」のどれかに対応させる
- 知識レベルは「〜を知っている」より「〜ができる」で聞く。章立ての出発点（前提にしてよい知識）を決めるのに使う

## 資格試験の場合に追加で聞くこと

| 項目 | 使い道 |
|---|---|
| 試験名（と版・年度） | 試験シラバスを信頼度 S の出典にする |
| 問題数 | 模擬試験モードの `meta.exam.questionCount` |
| 制限時間（分） | 模擬試験モードの `meta.exam.minutes` |
| 合格ライン（%）※分かれば | 模擬試験モードの `meta.exam.passingRate` |

## 聞かないこと

- 期限・1日の学習時間（学習エンジンの設計に使わないため）
- 自信の度合い（「不明」ボタンで代わりにする）

## 進め方

- 一度に全部を聞かず、まず3点を聞く。回答があいまいなら1つずつ確かめる
- 3点がそろったら、要約して確認してからフェーズ1に進む
